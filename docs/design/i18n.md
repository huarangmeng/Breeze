# i18n 基线

## 语言范围

当前应用先支持四种固定语言：

- 简体中文：`zh-Hans`
- 繁体中文：`zh-Hant`
- 英文：`en`
- 日语：`ja`

设置项额外提供 `system`，表示跟随系统语言。首次启动默认值为 `system`。

## 解析策略

应用启动后读取 `BreezeSettingsSnapshot.appLanguageTag`：

- 如果是固定语言，直接使用对应字符串表。
- 如果是 `system`，读取平台系统语言并映射到四种支持语言。
- 系统语言为繁体中文地区或 `zh-Hant` 时使用繁体中文。
- 系统语言为其他中文时使用简体中文。
- 系统语言为日语时使用日语。
- 其他语言默认回退英文。

各端系统语言读取在 `Platform.*.kt` 的 `getSystemLanguageTag()` actual 中实现。

## UI 接入

共享 UI 使用 `BreezeI18nProvider` 注入：

- `LocalBreezeStrings`：页面文案、状态消息、Provider 说明、模型说明。
- `LocalBreezeLanguagePreference`：当前用户偏好。
- `LocalBreezeResolvedLanguage`：最终解析后的显示语言。

新增页面文案时，优先加入 `app/shared/src/commonMain/kotlin/com/hrm/breeze/i18n/BreezeI18n.kt`，不要在页面里继续散落硬编码文案。

## 设置入口

语言设置放在 `SettingsHubScreen`，可选择：

- 跟随系统
- 简体中文
- 繁體中文
- English
- 日本語

选择后写入 `BreezeSettings.updateAppLanguageTag(...)`，界面会随 `settings.snapshot` 重新组合并立即切换语言。
